# Dr. Haitham Mostafa Youssef — Website

Static bilingual website (Arabic `index.html`, English `en.html`).

- Styles: `css/style.css`
- Script (WhatsApp booking, menu, FAQ filter, gallery viewer): `js/main.js`
- WhatsApp number: `WHATSAPP_NUMBER` at the top of `js/main.js`

Hosted on GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.

Live test URL: https://minshaawy.github.io/Haitham/
